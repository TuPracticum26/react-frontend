# Document Version Management System - React SPA Interface

Това е потребителският интерфейс на системата за управление на версии. Приложението е изградено като Single Page Application (SPA), което комуникира динамично с бакенд API-то.

## Технологичен стек
* **React 18:** Основна библиотека за изграждане на интерфейса.
* **Fetch API:** Използва се за асинхронна комуникация с бекенда без външни зависимости.
* **TipTap Editor:** Мощен "headless" Rich Text Editor за редактиране на документите.
* **TanStack Router:** Типово-безопасен рутер за управление на навигацията и състоянието на URL адресите.
* **TanStack Query:** Идеално интегруема с TanStack Router библиотека, помагаща за кеширане на информация и предоставяща много функционалности.
* **JWT Decode:** За обработка на информацията в потребителския токен.
* **CSS Modules:** За подредена стилизация на документите.

## Ключови функционалности
* **Lazy-Loaded Routes:** Всички линкове и компоненти са зарадени единствено, когато са на екрана, за да се спести място и да се увеличи скоростта на сайта.
* **Type-Safe Routing:** Благодарение на **TanStack Router**, линковете в приложението са валидни, параметрите в URL (като documentId) се управляват лесно и без грешки и достъпът до определени страници е защитен чрез логика за оторизация.
* **Rich Text Editing:** Интеграция на TipTap, позволяваща форматиране на текстовото съдържание (Bold, Itallic, Headers), наличие на плейсхолдъри за по-добра навигация при писане и автоматично запазване на съдържанието в JSON формат за бакенда.
* **Ролево базиран интерфейс (RBAC):** Динамично скриване/показване на компоненти спрямо правата на потребителя. 
* **Интерактивен Workflow:** Визуално проследяване на състоянието на версията (DRAFT → PENDING → APPROVED/REJECTED).

## Инсталация и Стартиране 
1. Инсталиране на стандартните зависимости:
    `npm install`
2. Инсталиране на специфичните библиотеки за проекта:
    `npm install @tanstack/react-router`
    `npm install @tiptap/react @tiptap/starter-kit @tiptap/extension-placeholder`
3. Стартирайте приложението:
    `npm run dev`

## Структура на проекта
* `/src/routes`: Дефиниция на маршрутите и логиката на TanStack Router.
* `/src/Documents`: Основните страници (DocumentView, CreateDocument и др.)
* `/src/Documents/EditDocuments/TipTapEditor`: Имплементация и конфигурация на Tiptap редактора.
* `/src/api`: Работа с Fetch API и дефиниция на заявките към бекенда.
* `/src/hooks`: Персонализирани hooks за управление на състоянието и аутентикацията.

## Комуникация с API (Fetch)
Фронтендът изпраща всички заявки към API (порт 8080 по подразбиране) с приложен Bearer token:
```javascript
    const response = await fetch(`/api/v1/users/${page}`, {
        headers: {
            Authorization: `Bearer ${JSON.parse(localStorage.getItem("auth"))?.token || ""}`,
        },
    });
```

### API Сервизи (Pagination & Filtering)
Тези функции управляват извличането на данни за страници (pagination) за по-добра производителност при големи обеми от информация. Бакендът на проекта използва **Spring Data Pageable**, което позволява на фронтенда да изисква само конкретна порция от данни, вместо да зарежда хиляди записи наведнъж.

* **getAllPendingVersions.js** извлича списък с всички версии в статус **PENDING**, предназначен за екрана за одобрение на REVIEWER ролята.
* **getTeamVersionsPage.js** връща списък с версиите на целия екип, позволявайки мониторинг на активността в системата.
* **getUsersPage.js** осигурява достъп до списъка с потребители за административни цели.
* **getVersionsPage.js** зарежда историята на версиите за конкретен потребител на части (страници), оптимизирайки скоростта на зареждане на профила на потребителя.

## Персонализирани Hooks (Custom Hooks)

* **useCreateDocument.js:** Създава нов документ, като изпраща форматираното съдържание от Tiptap към бекенда чрез защитена POST заявка.
* **useGetDocuments.js:** Асинхронно извлича списък с документи, управлява състоянието на зареждане (loading) и обработва пагинирани данни.
* **useGetUsers.js:** Капсулира логиката по комуникация с административния ендпоинт за извличане на потребители.
* **useGetUserVersions.js:** Извлича историята от версии на конкретен потребител чрез защитена заявка, базирана на неговото уникално ID.
* **useUpdateDocument.js:** Извършва частично актуализиране на документи чрез PATCH заявка, управлявайки състоянието на процеса.

## Помощни функции (Utils)
* **auth.js**: Централизиран модул за управление на автентикацията, който капсулира логиката по съхранение на JWT токена, проверка на потребителските роли и поддръжка на активната сесия в браузъра.
